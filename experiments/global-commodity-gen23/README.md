# WWO第23代经济算法源码镜像（只读研究资料）

这里是独立经济实验室默认分支中的 **Godot GDScript 经济算法源码镜像**，从已归档的第23代候选提取。它供阅读、比较、审查；不是可单独启动的Godot项目，不是独立Simulation，也不代表已合入WWO正式世界。

- 当前版本：`merchant-global-commodity-20261023`（第23代）。
- 完整可恢复的候选源码、地图依赖、存档、校验记录：[第23代私有Release](https://github.com/ryoumiyahayato/wwo-economy-lab/releases/tag/economy-gen23-closeout-20261024)。
- 本目录 `source/` 保留与发布包相同相对路径下的经济、市场、账物相关源码。完整第23代工程源码在Release附件 `01-source23.tar.gz`，不是GitHub自动生成的Source code zip。
- 原游戏主仓库：[ryoumiyahayato/wwo](https://github.com/ryoumiyahayato/wwo)，默认 `canonical/current-world`；本镜像不会覆盖它。
- 正式国际实物贸易尚未完成；全球宏观估计调配不是可提取库存。第23代GUI冷恢复和本地单笔真实买卖已在隔离副本验证，但全球指数改变真实经营报价仍未证实。
- 这里不包括Godot地图大资源、玩家存档、导入缓存、政治军事模拟。上述完整恢复依赖在Release分卷。

为避免增加分支，镜像直接归档在现有默认 `sandbox/main` 的本目录；历史旧分支、旧标签均保留，尚未删改。
