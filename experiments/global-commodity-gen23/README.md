# WWO Gen23 独立经济研究入口

第23代完整候选代码现在位于本仓库默认分支 `sandbox/main` 根目录：`project.godot`、`merchant/`、`scripts/` 和 `shaders/`。

这里不再保留重复的51文件副本，以免出现两个互相矛盾的“最新版”。

完整恢复所需的大型地图、地理数据、导入缓存、存档与历史报告在[第23代私有Release](https://github.com/ryoumiyahayato/wwo-economy-lab/releases/tag/economy-gen23-closeout-20261024)。此默认分支只是经校验的509文件源码快照，不能在缺少资源卷时直接启动Godot。

本仓库是经济实验室，冻结的游戏其他领域依赖仅供运行研究，不是向主WWO的同步源；主WWO及军事分支不受此更新影响。
